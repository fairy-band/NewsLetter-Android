---
name: pr
description: 현재 브랜치로 PR을 생성한다. "PR 올려줘", "PR 만들어줘" 같은 PR 생성 요청에 사용한다.
argument-hint: [이슈번호] [작업 요약 한 줄]
---

Agent 도구로 `pr-creator` 서브에이전트를 호출해 PR을 만든다. 입력: `$ARGUMENTS`

PR 작성에는 diff 전체와 이슈·계획서를 읽어야 해서 출력이 많다. 이를 메인 대화에 남기지 않으려고 서브에이전트에 맡긴다. 직접 git 명령이나 `gh`를 실행하지 않는다.

- 프롬프트에는 `입력: $ARGUMENTS`만 넘긴다. 비어 있으면 `입력: 없음`으로 넘긴다. 서브에이전트는 이 대화를 모르므로, 대화에서 알게 된 이슈 번호나 작업 요약이 있고 입력에 없다면 함께 적어 준다
- 서브에이전트가 반환한 결과(PR URL·라벨·리뷰어, 또는 중단 사유)를 그대로 전달한다
